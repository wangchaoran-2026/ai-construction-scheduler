# 供应商评估规则知识库

## 1. 评估维度与权重

供应商综合评估采用百分制，包含四个核心维度，权重分配如下：

| 评估维度 | 权重 | 评分依据 | 数据来源 |
|----------|------|----------|----------|
| 价格分   | 30%  | 投标报价与市场均价对比，最低价得满分，其余按比例折算 | 采购订单记录、市场价格指数 |
| 履约分   | 30%  | 准时交货率（权重20%）+ 逾期次数（权重10%） | ERP 系统交货记录 |
| 质量分   | 25%  | 产品合格率（权重15%）+ 退货率（权重10%） | 质检报告、退货记录 |
| 信用分   | 15%  | 企业信用评级（权重10%）+ 行政处罚/诉讼记录（权重5%） | 第三方信用平台（天眼查、企查查） |

**各维度评分细则：**

### 1.1 价格分（满分30分）
- **最低报价**：得满分30分。
- **其他报价**：得分 = 30 × (最低报价 / 当前供应商报价)  
  *（例如：最低报价100万，某供应商报价120万，则该供应商价格分=30×(100/120)=25分）*

### 1.2 履约分（满分30分，由两个子项组成）
- **准时交货率**（满分20分）  
  - 准时交货率 ≥ 98%：得20分  
  - 95% ≤ 准时率 < 98%：得15分  
  - 90% ≤ 准时率 < 95%：得10分  
  - 准时率 < 90%：得0分，并触发黄色预警（见风险阈值）

- **逾期次数**（满分10分，考核周期为近12个月）  
  - 0次：得10分  
  - 1~2次：得6分  
  - 3~4次：得3分  
  - ≥5次：得0分，并触发红色预警

### 1.3 质量分（满分25分，由两个子项组成）
- **产品合格率**（满分15分）  
  - 合格率 ≥ 98%：得15分  
  - 95% ≤ 合格率 < 98%：得12分  
  - 92% ≤ 合格率 < 95%：得8分  
  - 合格率 < 92%：得0分，并触发质量降级处理

- **退货率**（满分10分）  
  - 退货率 ≤ 1%：得10分  
  - 1% < 退货率 ≤ 3%：得7分  
  - 3% < 退货率 ≤ 5%：得4分  
  - 退货率 > 5%：得0分

### 1.4 信用分（满分15分，由两个子项组成）
- **企业信用评级**（满分10分）  
  - AAA级：得10分  
  - AA级：得8分  
  - A级：得6分  
  - B级及以下：得2分

- **行政处罚/诉讼记录**（满分5分，考核周期近3年）  
  - 无处罚、无重大诉讼：得5分  
  - 有1次一般处罚或小额诉讼：得3分  
  - 有2次及以上处罚或重大诉讼：得0分

## 2. 风险阈值

| 指标 | 阈值 | 触发动作 |
|------|------|----------|
| 准时交货率 | < 90% | 触发**黄色预警**，列入重点观察名单，限制新订单 |
| 准时交货率 | < 85% | 触发**红色预警**，暂停采购资格，启动备选供应商切换 |
| 质量合格率 | < 95% | **降级处理**，暂停供货，要求限期整改并重新送检 |
| 报价低于市场价 | > 5% | **人工复核**，由采购经理审批，防止低价中标后偷工减料 |
| 逾期次数 | ≥ 5次/年 | 直接进入黑名单候选，供应商评估总分扣减至55分以下 |

## 3. 供应商等级划分

根据综合评估得分，将供应商分为四个等级：

| 等级 | 总分范围 | 管理策略 |
|------|----------|----------|
| **优质供应商** | ≥ 85分 | 优先合作，加大采购份额，可签订年度框架协议 |
| **合格供应商** | 70 ~ 84分 | 正常合作，定期评估，关注改善情况 |
| **观察供应商** | 55 ~ 69分 | 限制采购量，要求提交整改计划，评估期缩短为每季度 |
| **黑名单供应商** | < 55分 或 存在严重违规（如商业贿赂、重大质量问题） | 终止合作，2年内不得参与投标 |

**备注：** 若供应商在合作期间发生重大安全事故、环保违规或失信行为，无论总分多少，立即列入黑名单。

## 4. 评分计算示例

假设某供应商 A 的近期数据如下：

- 报价：110万元（最低报价为100万元）  
- 准时交货率：96%  
- 逾期次数：1次  
- 产品合格率：97%  
- 退货率：2%  
- 企业信用评级：AA  
- 行政处罚：1次一般处罚  

**各维度得分：**

| 维度 | 子项 | 得分 | 计算过程 |
|------|------|------|----------|
| 价格分（30） | - | 27.27 | 30 × (100/110) ≈ 27.27 |
| 履约分（30） | 准时率（20） | 15 | 96% 对应 95%~98% 区间，得15分 |
|  | 逾期次数（10） | 6 | 1次对应 6分 |
| 质量分（25） | 合格率（15） | 12 | 97% 对应 95%~98% 区间，得12分 |
|  | 退货率（10） | 7 | 2% 对应 1%~3% 区间，得7分 |
| 信用分（15） | 信用评级（10） | 8 | AA 对应 8分 |
|  | 处罚记录（5） | 3 | 1次一般处罚，得3分 |

**总分 = 27.27 + (15+6) + (12+7) + (8+3) = 78.27分**

**等级判定：** 78.27 属于 70~84 区间，为**合格供应商**。  
**建议：** 正常合作，但需关注履约情况（准时率接近下限），可考虑将部分订单向优质供应商倾斜。

## 5. 数据来源与维护

### 5.1 数据来源
- **企业内部数据**：ERP / SRM 系统中的采购订单、交货记录、质检报告、退货数据。  
- **第三方信用平台**：天眼查、企查查、信用中国等，获取企业信用评级、行政处罚、诉讼信息。  
- **市场价格指数**：百年建筑网、我的钢铁网等行业网站发布的建材价格指数，用于计算报价偏差。

### 5.2 更新频率
- **动态指标**（报价、履约、质量等）：每季度更新一次。  
- **信用指标**：每年更新一次，重大事件即时更新。  
- **市场价格指数**：每月采集一次，作为价格评分基准。

### 5.3 维护责任人
- 采购部：负责价格、履约数据的录入与审核。  
- 质量部：负责质量数据的提供与复核。  
- 法务部/风控部：负责信用信息的核实与更新。  
- 系统管理员：定期导入外部数据，维护知识库参数（权重、阈值等）。

---

## 6. 调整与优化

本规则由供应链管理委员会每年评审一次，根据业务变化和供应商表现调整权重、阈值或等级划分。调整过程需保留版本记录，并及时同步至 AI 知识库及 SRM 系统。
